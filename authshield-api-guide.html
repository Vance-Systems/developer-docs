Integration Code Examples

Python (requests) 

import requests

url = "https://authshield-api.onrender.com/health"
headers = {
    "X-RapidAPI-Key": "YOUR_RAPIDAPI_KEY",
    "Content-Type": "application/json"
}

response = requests.get(url, headers=headers)
print(response.json())

Node.js (fetch) 

const fetch = require('node-fetch');

async function testApi() {
    const response = await fetch('https://authshield-api.onrender.com/health', {
        method: 'GET',
        headers: {
            'X-RapidAPI-Key': 'YOUR_RAPIDAPI_KEY',
            'Content-Type': 'application/json'
        }
    });
    const data = await response.json();
    console.log(data);
}
testApi();
